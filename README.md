# KettlebellPink (32:00 guided workout PWA)

## Files (upload all of them to the same folder)
index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png, favicon.png

## Host on GitHub Pages
1. Create a new public repository (e.g. `kettlebellpink`) and upload every file above to the repository root.
2. Settings > Pages > Build and deployment > Deploy from a branch > `main` / `(root)` > Save.
3. After a minute your app is at `https://<your-username>.github.io/kettlebellpink/`.

## Install
- iPhone: open the link in **Safari** > Share > **Add to Home Screen** > Add. Launch it from the pink kettlebell icon.
- Android: open in Chrome > menu > **Install app** (or use the in-app install button).

## Updating
Upload the new files over the old ones. If the phone still shows the old version, change `kettlebellpink-v4` in `sw.js` to a new name (e.g. `-v5`) and upload again.
